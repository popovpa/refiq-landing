Как работает RefIQ

Один путь от оффера до выплаты

  1. Оффер

    Бизнес создаёт оффер.

  2. Ссылка или QR

    Партнёр получает персональную ссылку или QR.

  3. Переход

    Пользователь переходит по ссылке.

  4. Сайт

    Пользователь совершает целевое действие.

  5. Postback

    Бизнес подтверждает конверсию через Postback.

  6. Комиссия

    RefIQ рассчитывает комиссию.

  7. Выплата

    Партнёр получает выплату.

Бизнес создаёт оффер, партнёр получает ссылку или QR, а RefIQ связывает клик, продажу и выплату в одном контуре.

Своя логика сайта

Сайт самостоятельно определяет ref-код и сохраняет его в cookie или собственном контексте.

  • Полный контроль над данными
  • Гибкие настройки
  • Поддержка и примеры кода

JavaScript

const match = location.search
  .match(/rqcid=([a-z0-9]{12})/);
if (match) {
  document.cookie = "rqcid=" + match[1]
    + ";path=/;max-age=31536000;SameSite=Lax";
}

Сохранение ref-контекста помогает не потерять переход между страницами сайта. Связь клика с конверсией выполняется через Postback.
