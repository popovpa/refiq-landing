Два равноправных способа подключения

Выберите вариант, который подходит устройству вашего сайта.

</>

JS SDK

Готовый вариант подключения

SDK автоматически определяет ref-контекст после перехода и помогает сохранять его между страницами сайта.

  • Простая установка
  • Автоматическое определение ref-контекста
  • Сохранение контекста перехода
▣

Своя логика сайта

Гибкий вариант через API

Сайт самостоятельно определяет ref-код и сохраняет его в cookie или собственном контексте.

  • Полный контроль над данными
  • Собственные правила хранения
  • Интеграция с текущими процессами
↗

Postback связывает клик и конверсию

Сохранение ref-контекста нужно, чтобы переход не потерялся до целевого действия. При подтверждении результата сайт передаёт конверсию через Postback.
